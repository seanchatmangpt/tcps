# Production System

## Preserve

TCPS preserves reversible lawful alternatives before consequential selection. One unsupported edge is topology, not graph failure.

## Fence

Every transition has an admission law. Missing authority, unsupported operation, path escape, policy drift, WIP overflow, tampered plan, failed postcondition, or receipt mismatch stops the line with a typed state.

## Calculus

```text
O  : observed work
O* : admitted bounded work
μ  : lawful manufacture
A  : observed consequence
R  : receipt(A)
```

### SELECT

SELECT chooses from a candidate graph. It does not execute.

### CONSTRUCT

CONSTRUCT manufactures candidate graphs, plans, generated projections, and intents. These artifacts have no ambient authority.

### DO

DO is the only consequential path. It rechecks authority and identity at the execution boundary and emits a receipt after verification.

## Jidoka

A violated invariant stops the line. The system does not “best effort” around a failed authority or verification boundary.

## Heijunka and WIP

`max_actions` is an explicit production WIP limit. Oversized work orders are split or re-authorized; they are never silently truncated.

## Kaizen

A failure becomes a new permanent guard, test, schema, refusal, verifier, or policy rule before the same boundary is considered repaired.
