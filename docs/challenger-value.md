# TCPS Challenger value compiler

The Challenger compiler treats commercial communication as another governed production projection.

```text
admitted evidence
  -> bounded narrative combinations
  -> DfCM Pareto frontier
  -> reversible buyer projection
  -> SHA-256 replay receipt
```

Run it from an installed/source `specify_cli` package:

```bash
python -m specify_cli.challenger case.json --json
```

It never searches for customer evidence, invents metrics, upgrades standing, or actuates a next step. `PROOF` requires `VERIFIED` evidence with a source and exact 40-hex subject. Inferences and hypotheses remain visibly labeled in the rendered brief.

The Pareto frontier maximizes evidence density, buyer relevance, falsifiability, and caller-admitted materiality while minimizing claim risk. The search is fail-closed above 4,096 candidate combinations. The recommended candidate is only a deterministic presentation default; `irreversible_selections=0`.
